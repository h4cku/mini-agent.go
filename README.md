# Mini-Agent.go

This project is a mini-agent application written in Go. It features components for agent logic, communication channels, configuration, memory management, and interaction with AI providers (e.g., Llama CPP).

## Building the Project

To build the `mini-agent` executable, navigate to the project's root directory and run:

```bash
make build
```

This will create an executable named `mini_agent` in the `bin/` directory.

## Running the Project

After building, you can run the agent using the `run` target:

```bash
make run
```

## Cleaning the Project

To remove the built executable, use the `clean` target:

```bash
make clean
```
